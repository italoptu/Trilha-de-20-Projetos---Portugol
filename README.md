# Trilha-de-20-Projetos---Portugol
Junto com chatGBT criei o 
🧑‍💻 Trilha de 20 Projetos desafios de Portugol, começando bem simples e aumentando a dificuldade aos poucos.

🟢 Nível 1 — Calculadora

Desafio: Crie uma calculadora que receba dois números e permita escolher entre:

Soma
Subtração
Multiplicação
Divisão

Treina: variáveis, entrada, saída e escolha.

🟢 Nível 2 — Verificador de idade

Desafio: Receba a idade de uma pessoa e informe se ela é:

Menor de idade
Maior de idade

Bônus: diferencie também criança, adolescente, adulto e idoso.

Treina: se/senão.

🟢 Nível 3 — Par ou ímpar

Desafio: Receba um número e descubra se ele é par ou ímpar.

Bônus: permita testar vários números.

Treina: operador % e repetição.

🟢 Nível 4 — Tabuada

Desafio: O usuário escolhe um número e o programa mostra sua tabuada de 1 a 10.

Bônus: permitir escolher até qual número deseja multiplicar.

Treina: para.

🟢 Nível 5 — Média do aluno

Desafio: Receba 3 notas e calcule a média.

Mostre:

Aprovado
Recuperação
Reprovado

Bônus: não permita notas menores que 0 ou maiores que 10.

Treina: condições e validação.

🟡 Nível 6 — Jogo de adivinhação

Desafio: O programa possui um número secreto. O jogador precisa tentar descobrir.

Depois de cada tentativa, informe:

Número maior
Número menor
Acertou

Bônus: conte quantas tentativas foram necessárias.

Treina: enquanto.

🟡 Nível 7 — Caixa simples

Desafio: Crie um pequeno caixa de supermercado.

O usuário informa:

Nome do produto
Preço
Quantidade

Calcule o valor total da compra.

Bônus: oferecer desconto dependendo do valor da compra.

🟡 Nível 8 — Caixa eletrônico

Desafio: Crie um sistema com menu:

Consultar saldo
Depositar
Sacar
Sair

O saldo deve continuar existindo enquanto o usuário utilizar o sistema.

Treina: menu + repetição + condições.

🟡 Nível 9 — Lista de compras

Desafio: Crie uma lista onde o usuário possa cadastrar vários produtos.

O programa deve permitir:

Adicionar produto
Listar produtos
Consultar produto
Sair

Treina: vetores.

🟡 Nível 10 — Cadastro de alunos

Desafio: Cadastre vários alunos.

Para cada aluno:

Nome
Idade
Nota

Depois permita consultar os alunos cadastrados.

Bônus: mostrar o aluno com maior nota.

🔴 Nível 11 — Sistema de estoque

Crie um estoque simples.

Cada produto deve possuir:

Nome
Quantidade
Preço

Menu:

Cadastrar produto
Consultar estoque
Entrada de produto
Saída de produto
Sair

Desafio extra: impedir saída quando não houver quantidade suficiente.

🔴 Nível 12 — Sistema de estacionamento

Crie um estacionamento com vagas.

O sistema deve permitir:

Registrar entrada
Registrar saída
Consultar vagas
Consultar veículos
Sair

Bônus: calcular o valor a pagar de acordo com o tempo.

🔴 Nível 13 — Sistema de biblioteca

Crie uma biblioteca simples.

Cada livro possui:

Título
Autor
Disponibilidade

Menu:

Cadastrar livro
Listar livros
Emprestar livro
Devolver livro
Consultar livro
Sair

Desafio extra: não permitir empréstimo de livro já emprestado.

🔴 Nível 14 — Sistema de hotel

Crie um hotel com vários quartos.

O sistema deve permitir:

Consultar quartos
Fazer reserva
Cancelar reserva
Consultar reserva
Sair

Cada quarto deve possuir:

Número
Valor
Status

Desafio extra: impedir duas reservas para o mesmo quarto.

🔴 Nível 15 — Quiz

Crie um jogo de perguntas e respostas.

Cada pergunta possui algumas alternativas.

O sistema deve:

Apresentar perguntas
Receber resposta
Verificar se está correta
Somar pontos
Mostrar resultado final

Bônus: criar níveis de dificuldade.

🔥 Nível 16 — Sistema bancário

Crie um banco simples.

Menu:

Criar conta
Consultar saldo
Depositar
Sacar
Transferir
Consultar dados
Sair

Desafio: trabalhar com mais de uma conta.

Bônus: criar um histórico simples de operações.

🔥 Nível 17 — Sistema de vendas

Crie um sistema para uma loja.

O sistema deve possuir:

Produtos
Preços
Estoque
Carrinho

O cliente poderá adicionar produtos ao carrinho e finalizar a compra.

No final mostre:

Produtos comprados
Quantidades
Subtotal
Desconto
Total
🔥 Nível 18 — Sistema de funcionários

Crie um sistema para cadastrar funcionários.

Cada funcionário possui:

Nome
Idade
Cargo
Salário

O sistema deve permitir:

Cadastrar
Listar
Pesquisar
Alterar
Excluir

Bônus: mostrar o funcionário com maior salário.

🔥 Nível 19 — RPG de batalha

Aqui você pode evoluir o seu BattleQuest. ⚔️

O jogador deverá criar um personagem.

Escolha:

Nome
Classe
Arma

Depois enfrente um oponente.

O personagem terá:

Vida
Ataque
Defesa
Dano da arma

Durante a batalha:

Ataque
Defender
Usar item
Fugir

Bônus: diferentes inimigos e armas.
